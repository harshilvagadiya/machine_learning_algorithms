# 🥞 Stacking (Stacked Generalization): Theory & Out-Of-Fold Meta-Learning

Stacked Generalization (Wolpert, 1992; Breiman, 1996) is an advanced ensemble technique where a meta-learner (Level-1 model) is trained on the predictions generated by multiple diverse base learners (Level-0 models).

---

## 1. The Critical Data Leakage Problem in Stacking

If base models are trained on the full training set $D_{\text{train}}$ and then generate predictions on the same $D_{\text{train}}$ to form the training set for the meta-learner:
- The base models will overfit their own training data.
- The meta-learner will learn that overfitted, artificially confident predictions are trustworthy.
- On test data $D_{\text{test}}$, the base models will make realistic errors, but the meta-learner will over-trust them, causing severe generalization collapse!

### The Solution: Out-Of-Fold (OOF) Prediction Generation
Stacking avoids this leakage via $K$-Fold Out-Of-Fold (OOF) cross-validation:

1. Partition training data $D_{\text{train}}$ into $K$ disjoint folds: $F_1, F_2, \dots, F_K$.
2. For each fold $k \in \{1, \dots, K\}$:
   - Train base models on the remaining $K-1$ folds: $D_{-k} = D_{\text{train}} \setminus F_k$.
   - Predict on the held-out fold $F_k$.
   - Concatenate these held-out predictions to form the uncorrupted meta-feature matrix $\tilde{X}_{\text{meta}} \in \mathbb{R}^{N \times M}$.
3. Fit the Meta-Learner $g$ on $(\tilde{X}_{\text{meta}}, y_{\text{train}})$.
4. Re-fit all base models on the entire $D_{\text{train}}$ so they are ready for production test inference.

---

## 2. Mathematical Formulation

### 2.1 Stacking Regressor
Base models: $h_1(x), h_2(x), \dots, h_M(x)$.
Meta-features for sample $x_i$:

$$\tilde{x}_i = \Big[ \hat{y}_{1,\text{OOF}}(x_i), \hat{y}_{2,\text{OOF}}(x_i), \dots, \hat{y}_{M,\text{OOF}}(x_i) \Big] \in \mathbb{R}^M$$

If `passthrough=True`, the original features $x_i$ are concatenated with the meta-features:

$$\tilde{x}_i^{\text{aug}} = \Big[ x_i, \hat{y}_{1,\text{OOF}}(x_i), \dots, \hat{y}_{M,\text{OOF}}(x_i) \Big]$$

The meta-learner $g$ (typically a regularized Ridge or ElasticNet) minimizes:

$$\min_{\beta_0, \beta} \sum_{i=1}^{N} \Big( y_i - \beta_0 - \sum_{m=1}^{M} \beta_m \hat{y}_{m,\text{OOF}}(x_i) \Big)^2 + \alpha \|\beta\|_2^2$$

### 2.2 Stacking Classifier
For classification, base models output probability distributions:

$$\tilde{x}_i = \Big[ P_1(y=c \mid x_i), \dots, P_M(y=c \mid x_i) \Big]$$

The meta-learner is typically an $L_2$-regularized Logistic Regression model.

## 3. Simple vs. Enterprise Production Example

### 3.1 Simple Example
```python
from sklearn.ensemble import StackingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.neighbors import KNeighborsClassifier

base_models = [
    ('rf', RandomForestClassifier(n_estimators=50, random_state=42)),
    ('knn', KNeighborsClassifier(n_neighbors=5))
]

meta_learner = LogisticRegression(C=1.0)

stacking = StackingClassifier(
    estimators=base_models,
    final_estimator=meta_learner,
    cv=5,
    passthrough=False,
    n_jobs=-1
)
stacking.fit(X_train, y_train)
```

### 3.2 Enterprise Production Stacking Pipeline
```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.compose import ColumnTransformer
from sklearn.ensemble import StackingRegressor
from sklearn.linear_model import Ridge, LinearRegression
from sklearn.tree import DecisionTreeRegressor
from sklearn.neighbors import KNeighborsRegressor

preprocessor = ColumnTransformer([
    ('num', StandardScaler(), num_cols),
    ('cat', OneHotEncoder(drop='first', handle_unknown='ignore'), cat_cols)
])

pipe_ols = Pipeline([('prep', preprocessor), ('reg', LinearRegression())])
pipe_dt = Pipeline([('prep', preprocessor), ('reg', DecisionTreeRegressor(max_depth=6, random_state=42))])
pipe_knn = Pipeline([('prep', preprocessor), ('reg', KNeighborsRegressor(n_neighbors=7))])

enterprise_stack = StackingRegressor(
    estimators=[
        ('ols', pipe_ols),
        ('dt', pipe_dt),
        ('knn', pipe_knn)
    ],
    final_estimator=Ridge(alpha=10.0),
    cv=5,
    passthrough=True,  # Allows meta-learner to access original raw signals
    n_jobs=-1
)
enterprise_stack.fit(X_train, y_train)
```
